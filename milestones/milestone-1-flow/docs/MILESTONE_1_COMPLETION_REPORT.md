### Flow Technical Specification

| Parameter / Requirement | Specification |
| :--- | :--- |
| **Flow Name** | `Standard Laptop Task` |
| **Application Scope** | `Global` |
| **Trigger Type** | `Service Catalog` (associated via Catalog Item Process Engine) OR `Record > Updated` on `sc_req_item` |
| **Trigger / Approval Condition** | `[Item]` is `Standard Laptop` `^` `[Approval]` is `Approved` `^` `[Approval]` changes to `Approved` |
| **Catalog Task Action** | `ServiceNow Core > Create Catalog Task` |
| **Requested Item Mapping** | Dynamic Data Pill: `{{Trigger.current}}` / `{{Trigger.request_item}}` |
| **Short Description** | `Configure Standard Laptop` |
| **Description** | `Hardware team: Please configure, image, and prepare the requested Standard Laptop for deployment to the user. Ensure standard corporate software packages are installed, verify hardware specs, and asset tag before dispatch.` |
| **Assignment Group** | `Hardware` *(Referenced to existing `sys_user_group` record)* |
| **Assigned To** | *(Unassigned - routes to Hardware group queue)* |
